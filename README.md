# Psychiatric Health Solution website

Website for Psychiatric Health Solution, P.L.L.C. (Ada Ojobo, PMHNP-BC). Built and managed by NS Tech Global Consulting.

- **Edit:** https://app.pagescms.org → sign in with GitHub → open this repo → edit → Save. Live in about a minute.
- **Hosting:** Cloudflare Pages (build `npm run build`, output `_site`).
- **Local preview:** `npm install` then `npm start`.
- **Privacy by design:** the site has no forms that collect health information. Booking, intake and video visits run on HIPAA-compliant platforms (Headway, Grow Therapy, SimplePractice).
- **Old site:** psychiatrichealthsolution.org should 301-redirect here; `src/_redirects` maps the old page paths.
- **Fonts:** Fraunces and Figtree, self-hosted (SIL Open Font License).
